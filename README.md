A one-line joke for make.fun's "One-Liner Laugh Lab" bounty: the excuse a robot vacuum gives after eating a sock. The program writes a single short funny line to `/output/entry.txt`, where a comedy-editor judge compares entries pairwise on funniness, originality, fit to the prompt, and tightness of wording.

## Run it

```sh
node main.ts
```
